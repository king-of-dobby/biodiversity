# BIOME · 생물다양성 탐구실

2022 개정 교육과정 통합과학2의 환경 변화와 생물다양성 보전을 탐구하는 한국어 수업용 시뮬레이션입니다.

## 실행

저장소 전체를 다운로드한 뒤 **`index.html`을 브라우저로 열면 됩니다.** `assets` 폴더를 같은 위치에 유지하세요. 설치나 빌드, 계정, 외부 API, 인터넷 연결이 필요하지 않습니다.

개발용 로컬 서버를 사용하려면 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

## 수업 흐름

1. 모둠별로 질문과 가설을 적고 역할을 나눕니다.
2. 서식지·오염·기온 중 한 조건을 바꿉니다. 복합 위기와 보전 비교 시나리오는 여러 조건이 함께 달라지는 비교 활동입니다.
3. 한 단계 진행하거나 자동 재생을 일시 정지하며 대조군과 실험군을 비교합니다.
4. 생물 카드를 눌러 먹이 관계를 확인하고, 다양성·개체 수 그래프와 단계별 표에서 근거를 찾습니다.
5. **관찰 기록 +**로 현재 수치를 노트에 넣고, 보전 방안과 모형의 한계를 토의합니다.
6. 초기화 전 CSV를 저장하고 새 실험과 비교합니다. 노트는 초기화해도 유지됩니다.

노트는 해당 브라우저의 로컬 저장소에만 저장됩니다. 여러 기기의 실시간 공동 편집 기능은 없으며, 같은 화면을 보며 함께 탐구하도록 구성했습니다. 저장소 이용이 제한된 브라우저에서는 노트 파일을 내려받아 보관하세요.

## 구성

- `index.html`: 탐구실, 기록, 교육과정 연계 안내
- `assets/style.css`: 반응형 화면, 인쇄, 움직임 줄이기 설정
- `assets/scene.js`: 자체 제작 SVG 생태계와 생물 일러스트
- `assets/app.js`: 가상 개체군 모형, 실험 진행, 그래프, 기록·내보내기

## 모형의 범위

5종의 가상 습지 생태계에서 밀도 의존적 증가와 환경 스트레스, 먹이 부족을 계산합니다. 동일 실험 번호에는 동일 환경 변동을 적용합니다. 종 수와 Shannon 다양성 지수를 표시하며 유전적 다양성과 생태계 다양성은 계산하지 않습니다. 개체 수 변화만으로 진화나 자연선택을 추론할 수 없습니다.

종과 계수는 수업용 가상 값입니다. 그림의 위치는 실제 공간 계산 결과가 아니며 한 단계는 실제 시간과 대응하지 않습니다. 생물 그림 하나는 약 10개체를 반올림해 나타냅니다. 실제 생태계 예측이나 보전 정책 평가용으로 사용할 수 없습니다. 상세 가정은 화면의 학습 가이드에서 확인할 수 있습니다.

## 검증

Chromium에서 동일 조건의 20단계 결과 일치, 서식지·오염 변화의 영향, 조건 고정, CSV(완료 실험 42행 + 머리글), 자동 진행·일시 정지, 노트 유지·복원, 모바일 레이아웃을 확인했습니다. 생물 설명, 실험군 확대, 지표 전환, 관찰 기록 추가도 브라우저에서 검증합니다.
